## ✨ New

- **Offline screen** — When the connection drops, a dedicated page explains what happened and lets you retry, while a small status badge shows when you are offline and confirms when you are back.

## 🛠️ Improved

- **Clearer game states** — Loading failures, filters that match nothing and missing rules pages now get their own screens, with the right action: try again, reset your filters, or head back home.
- **Keyboard hints** — Question navigation and tutorial controls now display their arrow shortcuts, and game shortcuts stay quiet while the changelog is open.
- **Install in your language** — The installable app now takes its name, description and shortcut from your language, and looks right on iPhone screens.
- **A better What's New** — The changelog now shows a loading skeleton with clear empty and error states, announces unread updates to screen readers, follows your language changes and gives entries more room.
- **Faster game start** — Animation code now loads only when the game needs it.

## 🐛 Fixed

- **Clear error messages** — Failed requests now explain what happened in your language, whether the selection was invalid, you were sending too many requests, or the server was slow or unavailable.
- **No more vanishing questions** — A failed refresh no longer clears the questions already on screen.
- **No duplicate questions** — New questions no longer repeat ones you have already seen in the current session.
- **Settings that behave** — Game settings and filters stay in sync and apply straight away, and saved settings that cannot be read reset themselves with a notice.
- **Safer source links** — Question sources now only open secure addresses, and the source section is hidden when nothing safe is left.
- **Tidy cards** — Long question, theme and trivia text now wraps instead of overflowing.
- **Tutorial focus fixed** — The tutorial keeps keyboard focus inside it, closes with Escape, and gives focus back when dismissed.
