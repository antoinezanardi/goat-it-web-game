## ✨ New

- **Question filters** — Choose exactly which questions come next by audience, difficulty, category and theme.
- **What's New** — Localized release notes now live on the home page and game sidebar, with an unread badge when a new version lands.
- **Adult content badge** — Questions with mature content are clearly flagged right on the card.

## 🛠️ Improved

- **Filters that stick** — Your filter choices are remembered between visits and survive reloads.
- **A smooth switch** — Applying new filters replaces only the questions coming up next, keeping the current one on screen.
- **Filters you can find** — Active filter counts on the sidebar and filter button, a one-click reset, and a tutorial step that shows how it all works.
- **No accidental losses** — Closing the filters with unapplied changes now asks you to confirm first.
- **Steadier connections** — Brief network hiccups are retried automatically instead of interrupting your game.
- **Faster repeat visits** — Dialogs now load on demand and static assets are cached longer.
- **Polished details** — Theme controls and tutorial popovers carry clearer screen-reader labels, with tidier popover layering and refreshed tab styling.

## 🐛 Fixed

- **Translations switch cleanly** — Changing the language mid-game now updates the questions in the right order.
- **A steady background** — The home page background no longer drifts as you scroll.
